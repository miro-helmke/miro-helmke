# Miro

Softwareentwickler mit Schwerpunkt auf Echtzeitkommunikation, Remote-Access und Desktop-Anwendungen. Ich arbeite hauptsächlich mit Rust und TypeScript.

### Projekte

| Projekt | Beschreibung | Technologien |
|---|---|---|
| **[Voice- & Chat-App](https://github.com/miro187/Schisscord-releases)** | Verschlüsselte Desktop-App für Chat, Sprach- und Gruppenanrufe, Bildschirmfreigabe und Dateitransfer, mit eigener Relay-Infrastruktur. | Rust · Tauri 2 · React · Nostr · Linux-Server |
| **[RustScreen](https://github.com/miro187/rustscreen)** | Selbst gehostete Bildschirmfreigabe und Fernsteuerung im Browser, Zugriff über Code und PIN ohne Portweiterleitung. | Rust · axum · tokio · ffmpeg · WebCodecs |
| **[InfinityNotes](https://github.com/miro187/InfinityNotes)** | Lokaler Arbeitsbereich auf einer unendlichen Canvas für Notizen, Aufgaben und Projektplanung, mit optionaler KI-Unterstützung. | Tauri 2 · Rust · React · SQLite |

### Technologien

- **Sprachen:** Rust, TypeScript
- **Backend:** axum, tokio, WebSockets
- **Frontend und Desktop:** React, Vite, Tailwind CSS, Tauri 2
- **Medien:** ffmpeg, H.264, WebCodecs
- **Datenbanken und Infrastruktur:** SQLite, Linux-Server, Caddy, Cloudflare Tunnel, GitHub Actions
- **Werkzeuge:** Claude Code, Cursor
